Privacy Policy

Classes Dashboard · Effective November 17, 2026

Classes Dashboard is a personal dashboard for viewing remaining class sessions in a Google Calendar. This policy explains how it handles Google Calendar data.

It's literally a private project, just for me, by me.

Calendar access and use

When you choose Connect Calendar or Sync, the dashboard asks Google for read-only Calendar access. Its current authorization scope is calendar.readonly, which technically permits the app to read calendars available to the authorizing Google Account. The dashboard’s code requests events only from the configured “3 - Classes” calendar.

The dashboard uses event titles, dates, recurrence information, and status returned by Google to count confirmed recurring class events whose titles begin with a course ID. It displays those counts in the dashboard. It does not use calendar contents for advertising, profiling, or any other purpose.

Storage and sharing

The dashboard runs in your browser. Calendar event data is requested directly from Google Calendar and processed in the browser; the dashboard does not send that event data to a separate server or store it in a database. The temporary access token is kept in page memory. The browser stores a small setting indicating that Calendar permission was previously granted; it does not store event details or the access token.

The dashboard does not sell or share calendar event data. Google receives the authorization and Calendar API requests and handles them under Google’s Privacy Policy. The static website is hosted by GitHub Pages, which serves the dashboard files.

Trello access and use

When you choose Connect Trello, the dashboard requests read-only access to your Trello account. The connection token can read boards available to your account, but the dashboard code requests cards only from the seven class lists configured by course ID. The dashboard displays open cards and any due dates on the matching class page.

Storage and sharing

Trello cards are requested directly from Trello and shown in your browser. The dashboard does not send card data to a separate server or store it in a database. The read-only Trello access token is saved in this browser’s local storage on this device so you do not need to reconnect whenever you return. Anyone with access to this browser profile can use that saved connection. The token is not included in the public website files or GitHub repository.

You can revoke Trello access from your Trello account’s connected apps or account settings, and you can remove the saved token by clearing this site’s browser storage. Trello handles authorization and API requests under Atlassian’s Privacy Policy.

Your choices

You can stop using the dashboard at any time. You can revoke its Google Account access from your Google Account’s third-party connections. You can also clear the dashboard’s website data in your browser.
